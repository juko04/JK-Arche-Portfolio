# Project Guidelines & Motion Standards (GSAP & Emil Kowalski Design Engineering)

See [GEMINI.md](./GEMINI.md) for the complete rules and standards for this repository.

## Quick Summary
- **GSAP 3:** Modern syntax only (`gsap.to()`, `gsap.fromTo()`, `gsap.timeline()`, `gsap.context()`). GPU properties (`x`, `y`, `scale`, `autoAlpha`). Zero layout thrashing.
- **ScrollTrigger:** Damped scrubbing (`scrub: 0.8`), `invalidateOnRefresh`, `force3D: true`.
- **Emil Kowalski Craft:** Directional easing (`ease-out` entry, `ease-in` exit), fast durations (<300ms), tactile press scale feedback, restraint over decoration.
- **Skills Available:** `.agents/skills/emil-design-eng/`, `.agents/skills/emil-animate/`, `.agents/skills/find-animation-opportunities/`, `.agents/skills/pick-ui-library/`, `.agents/skills/gsap/`, `.agents/skills/gsap-scrolltrigger/`.
